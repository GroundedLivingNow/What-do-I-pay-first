# What Do I Pay First? — Grounded Living Now

A mobile-friendly educational tool for prioritizing bills when there is not enough money for everything.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of a public GitHub repository. If GitHub Pages is already enabled for the account/repository, commit the files and allow the deployment to finish.

## Connect the Resource Library later
In `script.js`, replace:
`const RESOURCE_LIBRARY_URL = "";`
with the public Resource Library address between the quotation marks.

## Design note
The tool intentionally does not tell a user that a particular bill is legally safe to skip. It sorts broad categories by immediate essential-life consequences and tells the user to verify exact deadlines, grace periods, and provider options before paying.
